Project 4: "Teaching pressure and research output"

This folder contains all the material of the project.


SOFTWARE
--------
R 4.5.3 (the master script stops if R is not 4.5.x)
sfa 1.2.0 (version used by the instructor to verify the kit)
readxl, sandwich, lmtest (installed by template/00_setup.R if missing)
FEAR 5.0 (P. Wilson; not on CRAN, installed from the course zip file)
The versions of each run are saved in output/sessionInfo.txt.


GETTING THE PROJECT FROM GITHUB
-------------------------------
Private repository (group members only): https://github.com/Steffcar77/PEA_GroupA
  git clone https://github.com/Steffcar77/PEA_GroupA.git
  cd PEA_GroupA
Install R 4.5.3 and FEAR 5.0 (course zip file), then run the master as described below.
output/template_run/ is not in the repository: run_all_g4.R recreates it at every run.
.claude/ (local assistant settings) is excluded. template/ and docs/ are stored without
line-ending conversion (.gitattributes), so they stay byte-identical to the originals.
Group workflow: git pull before working; git add, git commit and git push after working.


HOW TO RUN
----------
Open a clean R session, set the working directory to this folder (PEA_GroupA) and run:
  source("run_all_g4.R")
or, from a terminal opened in this folder:
  Rscript run_all_g4.R
All paths are relative to this folder. Every file in output/ is regenerated by the scripts.
On Windows, if R warns that the inherited locale C.UTF-8 cannot be set, start Rscript
with the Windows default locale (remove LANG, LC_ALL and LC_CTYPE from that shell's
environment). Otherwise non-ASCII university names can fail the panel equality check.
Do not bypass that check or edit the instructor data to work around a locale mismatch.
After a successful complete run, presentation-only edits can be regenerated with:
  Rscript --vanilla run_all_g4.R --presentation-only
This mode runs g4/15 and g4/16 using existing tables and explicit DAG assumptions;
it does not refresh estimates or
sessionInfo.txt. The full default run remains required for submission.

Switch at the top of run_all_g4.R:
  RUN_SENSITIVITY <- TRUE   runs everything, including g4/11 and the g4/13 bootstrap. Use TRUE for
                            the submission, so that every output is regenerated.
  RUN_SENSITIVITY <- FALSE  skips g4/11 and the g4/13 bootstrap test while working;
                            their previous outputs stay in output/
                            and may be out of date.


CONTENTS
--------
run_all_g4.R   Master script. Runs everything in this order:
               1. copies template/ into output/template_run/ (template/ is never modified);
               2. runs the instructor scripts there: 00_setup, 00_simulated_causality,
                  01_prepare_data, 02_frontiers, 05_prepare_group_data,
                  06_group_project (GROUP = 4, RUN_FRONTIER = TRUE);
               3. checks: regenerated teaching panel equal in content to the original;
                  244 rows after 01, 183 lagged rows after 05, 180 rows / 60 universities
                  in the estimation sample of 06;
               4. runs the group scripts in g4/;
               5. saves software versions and sessionInfo() to output/sessionInfo.txt.
template/      Instructor kit, identical to the originals (read only).
docs/          Reference material: project booklet, R handout, data description, FEAR
               material, the group's systematic review (read only).
g4/            Group scripts (numbered from 07):
               07_sample_checks.R  sample flow by restriction, exposure check, missing values,
                                   adjunct-faculty 2023 check, sample descriptives.
               08_ratio_variation.R  SDs of log(students/faculty) between and within
                                   universities, 2020-2022, and figure of the variation.
               09_ratio_decomposition.R  dlog(S/F) = dlog S - dlog F: variance shares (raw,
                                   net of year effects, levels net of university and year
                                   effects), sign counts of the changes, figure.
               10_ols_specifications.R  seven OLS columns on the 06 sample (year effects /
                                   + 2018 field shares / + university effects, each without
                                   and with cost control; column (7) = (6) with regular
                                   students / faculty as the load); column (6) must
                                   reproduce 06.
               11_nhn_start_sensitivity.R  NHN of 06 (exposure in the frontier) from 32
                                   starting values, profile log-likelihood towards
                                   sigma_v -> 0, university-clustered SEs for the best NHN
                                   and for NHN_Z. Boundary solutions are diagnostics only.
                                   Runs only if RUN_SENSITIVITY = TRUE.
               12_research_frontier.R  Block 2 with FEAR: pooled research-only frontier
                                   2021-2023 (61 universities, 183 rows); inputs faculty and
                                   deflated current costs in t-1, output Scopus publications
                                   in t. Outliers (ap), convexity and returns-to-scale tests
                                   (fast versions, NSPLIT = 1000), estimator chosen by a fixed
                                   rule, output-oriented efficiency with subsampling 95%
                                   intervals, figure against the teaching load. Always runs
                                   (about 3 minutes); needs FEAR 5.0 and data/.
               13_frontier_robustness.R  Robustness of 12: one frontier per year, nominal
                                   costs, faculty + fellows, without ap potential outliers,
                                   without the 3 humanities universities with almost no
                                   Scopus output. Each version re-applies the estimator rule;
                                   summary with Spearman correlation against 12 and summary
                                   dot plot (fig_13_robustness_summary.png). Bootstrap
                                   convexity test with p-values (NREP = 200) only if
                                   RUN_SENSITIVITY (bootstrap test.rts dropped: over 30 min).
               15_final_figures_tables.R  Presentation assets from existing outputs only:
                                   six CSV tables, table_15_presentation.html (readable index),
                                   four 16:9 figures in PNG and vector PDF: variation,
                                   efficiency vs load, robustness, university quadrants.
                                   Quadrants use each university's median efficiency
                                   (1 / Farrell) and median publications over 2021-2023;
                                   cutoffs are medians across the 61 universities.
                                   No new estimation or dependencies. Runs after 13.
               16_causal_dag.R  Assumed causal DAG in base R (PNG/PDF, 16:9), with
                                   node, edge and assumptions tables. Checks acyclicity.
                                   Distinguishes the deterministic ratio S/F from causal
                                   hypotheses; students -> costs has unverified timing.
                                   Runs after 15 and is linked from the HTML index.
report/        note_for_professor.md  working note: findings, idea A vs idea B, proposal B,
                                   draft data request and causal design.
               project_diary.md  group working diary (in Italian): each step with date,
                                   what, why, results and problems; result notes and
                                   completion audit. Moved from CLAUDE.md on 24/11/2026.
data/          External data not included in the instructor kit (deviation 6 in CLAUDE.md):
               C16.pdf  ISTAT, Annuario Statistico Italiano 2023, chapter 16 "Prezzi",
                        downloaded on 23/11/2026 from
                        https://www.istat.it/storage/ASI/2023/capitoli/C16.pdf
               istat_nic_annual_2020_2022.csv  NIC consumer price index (whole nation),
                        INDICE GENERALE, annual mean, base 2015=100, from Tavola 16.10, p. 619:
                        2020 = 102.7, 2021 = 104.7, 2022 = 113.2. Used to deflate current-
                        management costs to 2020 euros (cost x NIC_2020 / NIC_t).
output/        Generated by the scripts:
               template_run/  copy of the kit and all instructor-script results;
               tables/        group tables (csv), presentation index (HTML);
               figures/       group figures (png; final figures also in PDF);
               sessionInfo.txt.
CLAUDE.md      Working notes of the group (plan, decisions, deviation log).
               Detailed diary and completion audit: report/project_diary.md.
.claude/       Local settings of the Claude Code assistant. NOT part of the submission:
